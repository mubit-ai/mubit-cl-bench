How Mubit helps

1
Each scan, the agent receives detected RF peaks (frequency, power, bandwidth). Some transmitters are active; others are dormant and invisible.
2
Mubit stores each scan's transmitter observations as a lesson via remember(intent="lesson"). Dormant channels accumulate — they're not visible every scan but they persist.
3
Before each report, Mubit retrieves relevant prior observations via recall(). The agent combines current scan data with accumulated history to produce a complete transmitter map.
4
Result: IoU climbs steadily. By scan 70+, the agent has observed every channel multiple times and achieves 85%+ accuracy. The stateless baseline (no memory) stays at ~24% — it can only report what's visible in the current scan.
